# Zach Hubbard — Portfolio Website

Source code for my game and software development portfolio website — zachhubbard.com

## Tech Stack

- **React 18** — UI framework
- **Vite** — build tool and dev server
- **React Router v6** — hash-based routing (`createHashRouter`)
- **MUI v5** — Grid layout and theming
- **Bootstrap 5 / React Bootstrap** — Navbar component
- **CSS custom properties** — site-wide design tokens
